# Notes App

A simple notes app made with HTML, CSS and JavaScript.

## Features

- Write and add notes
- Delete notes
- Notes are saved in the browser, so they stay after refreshing the page

## Files

- `index.html` – the page structure
- `style.css` – the styling
- `script.js` – adding, deleting and saving notes

## How to Run

Open `index.html` in any web browser.

## What I Learned

- Storing data in an array
- Creating elements with `document.createElement`
- Saving data with `localStorage`
- Converting data with `JSON.stringify` and `JSON.parse`
